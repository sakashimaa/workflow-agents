# Использование AI

Проект реализован при помощи OpenAI Codex по предоставленному PDF-ТЗ. AI использовался для чтения требований, проектирования, написания кода и документации, запуска миграций/сборок, создания и выполнения unit/E2E-тестов, диагностики hydration race и подготовки небольших тематических Git-коммитов.

Внешний код из ответов или закрытых репозиториев не копировался. Использованы только заявленные npm-пакеты и их публичные API. Перед эксплуатацией человек должен провести code review, заменить demo-секреты, проверить требования своей инфраструктуры и выполнить независимый security review.
